# Service Dispatch — Pick Your Services

An interactive service selection and dispatch web application with a vibrant neobrutalist aesthetic, dynamic pricing calculator, category filtering, search, and dispatch summary modal.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+) and npm

### Local Development

1. Install dependencies (if not already installed):
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the local URL (typically `http://localhost:5173`).

### Production Build

```bash
npm run build
npm run preview
```
